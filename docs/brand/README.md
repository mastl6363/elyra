# Elyra brand mark

The Elyra mark combines an open geometric **E** with a continuous audio
waveform. Its silhouette stays recognizable in the Windows taskbar while the
waveform connects the mark to music without relying on a generic music-note
icon.

## Palette

- Elyra violet: `#9D7BFF`
- Canvas: `#0A0A0F`
- Highlight: `#F4F4F5`

## Assets

- App background: `src/Elyra/Resources/AppIcon/appicon.svg`
- Adaptive foreground: `src/Elyra/Resources/AppIcon/appiconfg.svg`
- Splash mark: `src/Elyra/Resources/Splash/splash.svg`
- UI component: `src/Elyra/Components/Shared/ElyraMark.razor`
- Initial generated concept: `elyra-logo-concept.png`

## Concept prompt

> Create an original, distinctive symbol for Elyra, combining an abstract
> capital E with the rhythm of a smooth audio waveform in one unified geometric
> glyph. Clean vector-friendly mark, flat colors, minimal, premium modern music
> technology aesthetic. Strong balanced silhouette, legible at 16 px. Elyra
> violet, deep charcoal and off-white. No text, literal musical note,
> headphones, speaker, mockup, 3D, shadows, watermark or existing trademark.

The concept was generated with the built-in image generation tool and then
redrawn as deterministic SVG geometry for production use.
